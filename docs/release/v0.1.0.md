# Caudex v0.1.0 release-readiness record

Release date: 2026-07-26

This is a staged release-readiness record, not evidence of a public release.
The `v0.1.0` tag, npm publication, and public native C downloads are still
deliberate follow-up actions and are not performed by local validation.

All CWE-082 gates are represented by executable checks or reviewed records:

- Two methodologies: double progression and RPE top-set/backoff execute through
  the official npm/WebAssembly recommendation runtime.
- npm package: packed, installed, compiled, and run from clean Node/browser
  consumers.
- Zig package: declared-path source package and clean custom-methodology
  consumer.
- C artifacts: six-target static/shared matrix with checksums and link tests.
- Cross-language conformance: Zig, C, WASM, and TypeScript fingerprints.
- Quickstarts: packed Node and browser examples plus direct Zig and C examples.
- Migration/version policy: [`versioning.md`](versioning.md).
- Security review: [`security-review-v0.1.0.md`](security-review-v0.1.0.md).
- License review: [`license-review-v0.1.0.md`](license-review-v0.1.0.md).

`zig build test` is the release gate. Publication still requires the immutable
`v0.1.0` tag and the protected npm release workflow; this implementation does
not create or push that tag.
