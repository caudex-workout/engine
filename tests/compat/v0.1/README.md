# v0.1.0 compatibility record

This directory records the first released contract line. The current
repository’s clean Zig consumer, C ABI smoke tests, npm/TypeScript tests, CLI
tests, JSON fixtures, methodology state, and SQLite migration tests are the
executable compatibility coverage for this release line.

The manifest is historical metadata, not a permission to silently update old
fixtures. When a future release intentionally changes behavior, add a new
record and classify the change as additive, behavioral, deprecated, or
breaking, with changelog/migration/ADR notes as appropriate.
