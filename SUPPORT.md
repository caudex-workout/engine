# Support

Start with the consumer guides in `README.md`, the quickstart/concepts guide,
and the contributor setup/testing guides. For a reproducible defect, open the
bug form with the exact Caudex version, surface, toolchain, target triple,
request/fixture, and issue or explanation codes.

Questions about integrating a host persistence layer belong in the adapter and
data-mapping documentation. Feature requests should explain the host use case
and deterministic contract impact. Security reports belong in `SECURITY.md`,
not a public issue.
